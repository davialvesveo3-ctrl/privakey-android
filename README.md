# 💎 PrismKey

**PrismKey** é um teclado virtual moderno, minimalista e personalizável para Android, desenvolvido em **Kotlin** e **Jetpack Compose** com foco em privacidade (*local-first*), estética visual e produtividade com Inteligência Artificial.

> ⚠️ **Status do Projeto:** Versão **Alpha (`v1.0.0-alpha`)** em fase ativa de testes e desenvolvimento.

---

## ✨ Principais Recursos

* **🎨 Temas & Personalização Visual:** Inclui o tema translúcido **Liquid Glass**, modos Claro/Escuro automáticos e suporte para **foto personalizada da galeria** com enquadramento integrado e controle de escurecimento das teclas.
* **🤖 Ferramentas de IA Integradas (Opcional):** Correção ortográfica, reescrita em diferentes tons, sugestões rápidas de resposta e tradução direto na barra superior do teclado via API do Gemini.
* **🔍 Lupa Tradutora Flutuante:** Serviço de acessibilidade sob demanda para ler e traduzir textos visíveis na tela sobre qualquer aplicativo (com suporte online e offline via ML Kit).
* **🔒 Privacidade Local-First:** Sem servidores externos ou rastreamento de digitação. Suas configurações, imagens de fundo e chave de API ficam armazenadas exclusivamente no aparelho.

---

## 📥 Como Testar (Alpha)

1. Acesse a aba [**Releases**](../../releases) aqui no repositório.
2. Baixe o arquivo `.apk` mais recente (ex.: `PrismKeyV1.0.0.apk`).
3. Instale o aplicativo no seu Android, ative o teclado nas configurações de idioma/entrada e defina-o como padrão.
